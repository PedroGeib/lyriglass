Como conseguir o Client ID

O Client ID vem de um app gratuito que você cria no painel de desenvolvedores do Spotify. Leva uns 2 minutos:

Abrir o Spotify Developer Dashboard ↗

developer.spotify.com/dashboard

  1. Entre com a sua conta do Spotify. Na primeira vez, aceite os termos de desenvolvedor.
  2. Clique em Create app.
  3. Em App name e App description, escreva qualquer coisa (por exemplo, Lyriglass).
  4. Em Redirect URIs, cole o endereço do campo Redirect URI acima (use o botão Copiar) e clique em Add.
  5. Em Which API/SDKs are you planning to use?, marque Web API, aceite os termos e clique em Save.
  6. Na página do app criado, copie o Client ID (32 letras e números) e cole no campo Client ID acima.
  7. Clique em Conectar com Spotify e autorize no navegador.

Apps novos ficam em modo de desenvolvimento: só entram contas cadastradas em User Management, no painel do app. A sua conta, como dona do app, já está liberada.

O login usa PKCE: nenhum Client Secret é necessário nem armazenado.

Modo Jam

Mostre um QR Code no overlay para os amigos entrarem na sua Jam — ou abrirem a música que está tocando.

Convite

No Spotify, inicie uma Jam → Convidar → Copiar link. Sem link, o QR Code abre a música atual.
Prévia

O Spotify não oferece uma API pública para criar ou gerenciar Jams, então o app apenas compartilha o link.
