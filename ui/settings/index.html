How to get a Client ID

The Client ID comes from a free app you create in Spotify’s developer dashboard. It takes about 2 minutes:

Open the Spotify Developer Dashboard ↗

developer.spotify.com/dashboard

  1. Log in with your Spotify account. The first time, accept the developer terms.
  2. Click Create app.
  3. In App name and App description, enter anything (for example, Lyriglass).
  4. Under Redirect URIs, paste the address from the Redirect URI field above (use the Copy button) and click Add.
  5. Under Which API/SDKs are you planning to use?, check Web API, accept the terms and click Save.
  6. On the new app’s page, copy the Client ID (32 letters and numbers) and paste it into the Client ID field above.
  7. Click Connect with Spotify and approve access in your browser.

New apps start in development mode: only accounts added under User Management in the app’s dashboard can log in. Your own account, as the app owner, already has access.

Login uses PKCE: no Client Secret is needed or stored.
